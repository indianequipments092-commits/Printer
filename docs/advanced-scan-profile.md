# Advanced Scan Profile

PrintBridge exposes controls only when the selected device advertises support.

- DPI: 75–1200 validation boundary
- Brightness: -100 to +100
- Contrast: -100 to +100
- Color: color, grayscale, black-and-white
- Paper: A4, A5, Letter and device-supported/custom sizes
- Orientation: 0/90/180/270
- Duplex: capability dependent
- Auto-crop: capability/pipeline dependent
- Deskew: capability/pipeline dependent
- Output: JPEG, PNG or PDF
- Multi-page: ordered page collection with preview/reprocess states
