# PrintBridge Acceptance Checklist

## Software acceptance
- [x] Unified scan/print contracts
- [x] Scan settings validation
- [x] Brightness and contrast controls
- [x] DPI/quality validation
- [x] Color/grayscale/B&W modes
- [x] Paper/orientation metadata
- [x] Crop/deskew/rotation controls
- [x] JPEG/PNG/PDF output contracts
- [x] Queue/state/error model
- [x] Cancellation/retry boundaries
- [x] USB/network provider boundaries
- [x] Deterministic validation tests
- [x] Release/compatibility documentation

## Hardware acceptance — requires real devices
- [ ] Android USB scanner test
- [ ] Android wireless scanner test
- [ ] Desktop USB scanner test
- [ ] Desktop wireless scanner test
- [ ] Physical print test
- [ ] Duplex test where supported
- [ ] Real scan image/PDF quality test
- [ ] Brightness/contrast/DPI behavior test

Do not mark hardware items complete until tested on actual supported hardware.
